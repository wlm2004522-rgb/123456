# AI Anime H5 Static

《热搜之外》四幕互动 H5 静态部署包。

## 文件结构
- `index.html`：网页入口
- `style.css`：页面样式与手机适配
- `app.js`：剧情、选择分支和交互逻辑
- `assets/`：页面插画资源
- `部署说明.txt`：部署步骤

## 部署
1. 解压 ZIP。
2. 将解压后的整个文件夹上传到静态网站托管平台，或把文件夹内全部内容拖入 Netlify Drop。
3. 确保 `index.html` 位于网站根目录。
4. 部署成功后，用手机浏览器打开平台提供的网址即可。

## 本地预览
建议使用静态服务器预览；直接双击 `index.html` 通常也可查看，但部分浏览器对本地文件资源有限制。
